# Humanizer Skill Profile

Use only when editing or drafting prose for a human reader.

Do:

- Preserve the original technical meaning.
- Replace inflated claims with concrete details.
- Remove vague attributions unless a source is named.
- Prefer plain verbs over promotional phrasing.
- Vary sentence structure naturally.
- Keep the author's intended tone.

Avoid common AI-writing patterns:

- "serves as", "stands as", "testament", "pivotal", "crucial"
- vague "experts say" or "industry reports" claims
- forced groups of three
- overused em dashes
- generic upbeat conclusions
- chatty filler such as "I hope this helps"

Do not humanize command output, JSON, logs, code, tables, health checks, or
diagnostics. For those, preserve structure and accuracy.
