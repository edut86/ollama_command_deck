# Frontend Design Skill Profile

Use for UI, layout, responsive behavior, visual refinement, and frontend
interaction work.

Principles:

- Build the real usable interface first.
- Match the domain: operational tools should be dense, calm, and scannable.
- Keep controls familiar: selects for option sets, toggles for booleans,
  sliders/inputs for numbers, icon buttons for common tool actions.
- Use stable dimensions for toolbars, panes, tables, grids, and fixed-format UI.
- Make text fit at mobile and desktop sizes.
- Avoid generic AI-looking decoration, purple gradient defaults, and gratuitous
  nested cards.
- Respect existing design tokens and component patterns in the repo.

Before finishing frontend work, check the actual rendered layout when practical.
