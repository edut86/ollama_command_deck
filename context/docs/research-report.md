# Deep Research Report Guidance

Use this context only for the `deep_research` profile or explicit requests for a detailed research report.

## Workflow

1. Break the user subject into 3-6 research angles.
2. Search for current, authoritative sources for each angle.
3. Prefer primary sources, official documentation, standards, peer-reviewed work, and reputable technical reporting.
4. Compare sources before making claims. Mark uncertain or conflicting information clearly.
5. Write a standalone Markdown report for the document canvas.

## Report Shape

Use this structure unless the user asks for a different format:

- Title
- Executive summary
- Scope and assumptions
- Key findings
- Detailed analysis
- Risks, gaps, and open questions
- Recommendations or next steps
- Sources and notes

## Citation Style

Use Markdown links inline when source URLs are known. Do not invent citations. If search results do not expose enough source detail, say that source detail was unavailable and label the section as preliminary.

## Canvas Output Rules

The final answer should be the complete report only. Do not include tool logs, chat transcript labels, or phrases like "here is the report." Keep it ready to paste directly into the canvas.
